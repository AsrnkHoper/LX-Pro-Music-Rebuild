# 🏠 主页导航结构设计
> 目标：先做**外观 + 交互**，不接真实数据
> 风格：灰黑忧郁 · 深空感 · 高级

---

## 一、主页定位

主页 = **功能入口总览**，用户一进来能看到所有主要功能，快速跳转。

不是"播放页"，而是"导航页"。

---

## 二、主页元素清单

### 核心导航入口（你要的）
| 入口 | 图标 | 说明 |
|---|---|---|
| 🔍 **搜索** | 放大镜 | 搜索歌曲/歌手/专辑 |
| ❤️ **我的歌单** | 歌单/列表 | 收藏的歌单 |
| 📊 **听歌统计** | 图表 | 听歌时长/排行/习惯 |
| ⚙️ **设置** | 齿轮 | 应用设置 |

### 建议补充的入口
| 入口 | 说明 |
|---|---|
| 🎵 **最近播放** | 继续听 |
| ⭐ **我的收藏** | 喜欢的歌 |
| 📥 **下载管理** | 已下载 |
| 🕐 **播放历史** | 听过什么 |
| 🎧 **本地音乐** | 设备里的歌 |
| 🌙 **睡眠定时** | 定时关闭 |

## 三、布局方案

### 方案 1：功能卡片网格（推荐）
```
┌────────────────────────────────┐
│  Good evening.                 │  顶部问候
│  今晚也想听点安静的吗？          │
├────────────────────────────────┤
│  🔍 搜索歌曲 / 歌手 / 专辑       │  搜索栏（胶囊）
├────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐    │
│  │  🔍      │  │  ❤️      │    │  2×2 功能大卡
│  │  搜索    │  │ 我的歌单  │    │
│  └──────────┘  └──────────┘    │
│  ┌──────────┐  ┌──────────┐    │
│  │  📊      │  │  ⚙️      │    │
│  │ 听歌统计  │  │  设置    │    │
│  └──────────┘  └──────────┘    │
├────────────────────────────────┤
│  最近播放              全部 >   │
│  ▢ ▢ ▢ ▢  （横滑）             │
├────────────────────────────────┤
│  快捷入口                       │
│  收藏 · 下载 · 历史 · 本地      │  小图标行
├────────────────────────────────┤
│  ▶ 迷你播放条（悬浮）            │
├────────────────────────────────┤
│  首页  发现  歌单  我的          │  底部导航
└────────────────────────────────┘
```

### 方案 2：列表式（更简洁）
每个功能一行，带图标 + 标题 + 副标题 + 箭头

### 方案 3：环形/放射式（最有空间感）
功能入口围绕中心排列成环，但交互复杂，暂不推荐

> **采用方案 1**，符合深空高级感，2×2 大卡最有存在感。

---

## 四、交互设计（只做外观交互）

| 元素 | 交互 |
|---|---|
| 功能卡片 | 点击 → 缩放反馈 + 高亮边框（暂不跳转，或弹出占位页） |
| 搜索栏 | 点击 → 展开输入框（外观） |
| 最近播放 | 横滑 |
| 底部导航 | 点击切换选中态 |
| 迷你播放条 | 点击播放/暂停（图标切换） |
| 卡片进入 | 错落淡入上浮动画 |

---

## 五、视觉规范（沿用深空风）

```
背景      #070709 深空黑
卡片      rgba(255,255,255,0.045) 玻璃
卡片边框  rgba(255,255,255,0.08)
强调      #6E7A8A 冷灰蓝
文字主    #EDEDED
文字次    #8A8A8E
文字辅    #4A4A4E
```

- 卡片圆角 22dp
- 卡片有**微光晕**（hover/active 时）
- 图标用**线性描边**风格，统一 1.8px
- 保留深空背景（星空/光晕）+ 噪点
