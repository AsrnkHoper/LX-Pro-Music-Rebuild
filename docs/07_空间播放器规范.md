## 二、关键技术

### 1. 「屏幕比例定位」——适配所有屏幕
不再用固定世界坐标，而是**按屏幕比例**定义，构建时换算：

```js
// 屏幕比例 → 世界坐标
halfH = tan(fov/2) * R
halfW = halfH * (innerWidth/innerHeight)

x = (sf*2 - 1) * halfW        // sf: 屏幕横向比例 0~1
y = (1 - sv*2) * halfH        // sv: 屏幕纵向比例 0~1
z = -R

宽 ww = fw * 2 * halfW         // fw: 屏宽占比
高 hh = square ? ww : fh*2*halfH
```
→ 无论手机长宽比如何，**歌词永远在左半屏、封面永远在右半屏**。

### 2. 「固定倾斜」机制（tilt）
```js
if (u.tilt === undefined) {
  m.lookAt(camera.position);          // 正对镜头（billboard）
} else {
  const baseYaw = atan2(-x, -z);      // 先朝向镜头
  m.rotation.set(0, baseYaw + u.tilt, 0);  // 再叠加倾斜角
}
```
- **有 `tilt`** → 固定倾斜，不跟随相机 → 有透视、有空间感
- **无 `tilt`** → 始终正对镜头 → 交互元素（进度条/按钮）点得准

### 3. 裸元素（bare）
`bare:true` 的控件用 `PlaneGeometry`（纯平面，无底板无厚度），
`redrawWidget` 跳过背景绘制 → 元素只是**浮在空间里的内容**，没有卡片感。

### 4. 自适应像素密度
小控件自动提高像素密度，保证清晰：
```js
const ppm = Math.max(PPM, Math.round(620 / ww));
```

### 5. 歌词：长图 + offset 滚动
```
整首歌 → 画进一张长图（按最多行数定高）
      → 面板只显示一段窗口：tex.repeat.y
      → 滚动 = 改 tex.offset.y（GPU 采样，零重绘）
      → 当前句变化时才重画长图（更新高亮）
```
高亮规则（自然形成渐隐，无需遮罩）：

| 距离当前句 | 透明度 | 字号 |
|---|---|---|
| **0** | 0.97 | 0.33P |
| ±1 | 0.44 | 0.27P |
| ±2 | 0.22 | 0.25P |
| ≥3 | 0.10 | 0.24P |

### 6. 进度条拖动（3D 空间内）
```
pointerdown → 射线拾取 → 命中 'seek' 区域
           → 按 UV.x 立即 seek
pointermove → 每帧重新拾取 → 实时跟随手指（此时不旋转相机）
```

## 三、性能策略

| 刷新对象 | 时机 |
|---|---|
| 歌词长图 | **仅当前句变化时** |
| 控制面板 | **仅秒数变化时** |
| 歌词滚动 | 每帧只改 `tex.offset.y`（GPU 侧） |
| 切歌 | 重画整页 + 歌词瞬移 |

## 四、可调参数

| 想改 | 改哪 |
|---|---|
| 歌词位置/大小 | `PAGES.now.widgets` 里 lyric3d 的 `sf/sv/fw/fh` |
| 封面位置/大小 | cover 的 `sf/sv/fw`（`square:true` 保证正方形） |
| **倾斜角度** | `tilt`（当前 ±0.32 rad ≈ ±18°） |
| 控制条位置 | transport 的 `sf/sv/fw/fh` |
| 球半径 | `PAGES.now.radius`（当前 8） |
| 相机转动范围 | `PAGES.now.cam`（当前 ±0.88 rad） |
| 歌词行高/高亮 | `DRAW.lyric3d` |
| 曲目与歌词 | `TRACKS` 数组 |
