# 🌌 空间重组设计思想（不是复刻，是重组）
> 对 `docs/09_空间化建构方案.md` 的方向性修正
> 一句话：**LX_Pro 把信息"分页"放进一面屏幕；我们把信息"分位"放进一个球面。**

---

## 一、核心思想

**1:1 复刻是错误的。** LX_Pro 是平面 UI，受限于一面屏幕，只能：
```
分页（Tab 切换）→ 子页面栈 → 弹窗层叠 → 双页滑动
```
每一刻都只能看一个"页面"。

**我们的空间没有这个限制：**
- 可以**同时**展示歌词 + 封面 + 进度 + 队列 + 设置
- 信息的组织方式从"时间顺序（翻页）"变成"**空间位置（环绕）**"
- "页面"这个概念消失，变成"**焦点**"

> 原则：**空间里已有的、更好的形式，不要为了对齐 LX_Pro 而改回去。**

---

## 二、扁平 → 空间 的对照表

| LX_Pro（黑板式） | Rebuild（空间式） | 说明 |
|---|---|---|
| **分页 Tab**（热门/最新、歌单/排行） | **角度**：相邻页放在左右两侧，轻转即见 | 不需要点 Tab |
| **双页：封面 ⇄ 歌词** | **同屏**：左歌词 + 右封面 ✓（已实现） | 我们一次看全 |
| **子页面栈**（歌单→详情→歌手） | **空间分层**：列表在前、详情在左、歌手在右 | 转视角"钻进去" |
| **弹窗**（菜单/设置/歌单选择） | **空间焦点**：把"弹层"变成"环绕中的一面" | 转到就看，转走就完 |
| **抽屉导航（14 项）** | **环绕入口**：菜单位于四周，像车站指示牌 | 永远在场，不必"打开" |
| **批量操作条** | **环绕操作环**：操作围在目标周围 | 直觉化 |
| **列表 + 详情两级** | **同屏组合**：头图卡 + 列表同屏 | 一眼看上下文 |
| **播放队列（上滑弹层）** | **左转焦点**：队列一直浮在左侧 | 想看就转 |

## 三、关键空间重组示例

### 1. 播放页（保持不变的优势形式 ✓）

```
        ┌──────────────┐
  队列  │ 歌词（左）     │ 封面（右）
  一直  │ 高亮在中间     │ │  │
  在左  │              │ 信息行
  转即见│              │ 进度+控制
        └──────────────┘
```
- **不翻页**：LX_Pro 要滑到第 2 页看歌词 → 我们同屏
- **增强方向**：不是"复制它的页"，而是利用球面——
  - 左转：队列（已有）
  - 右转：**更多操作**（5 个圆形按钮）
  - 下转：**播放设置**（6 项）
  - 长按封面：**操作环**（12 项）
- 这些都是"**同一空间里的其他面**"，不是子页面

### 2. 抽屉导航（不是弹层，是环绕）

LX_Pro：点 ☰ → 一个滑出面板（挡住内容）
Rebuild：**菜单弧永远在左后方**——转动视角 45° 就能看到全部 14 项入口，转回来即回到内容。☰ 按钮只是"快速把视角转过去"的快捷键。

### 3. 歌单详情（不是子页，是同屏）

LX_Pro：列表页 → 点歌单 → 详情页（返回栈）
Rebuild：**当前空间 = 歌单列表**；点某个歌单 → 该歌单的"头图卡 + 歌曲列表"在**同一空间的右侧**展开（转视角看到），列表仍在左侧。不用"回去"。

### 4. 评论（不是子页，是环绕面）

LX_Pro：播放页 → 点评论 → 评论页（返回）
Rebuild：评论**挂在播放页的右下方**，转视角即可浏览，转回来继续听歌。上下文不断裂。

## 四、由此得出的组织规则

| 规则 | 说明 |
|---|---|
| **一个空间 = 一个焦点 + 若干环绕面** | 正面放主内容，其他信息按重要性排在四周 |
| **凡是"切换"都改成"转动"** | Tab、页面、弹窗 → 都是角度上的面 |
| **同屏优先** | 能同时展示就不分级（歌词+封面 ✓） |
| **环绕比弹层高级** | 菜单、操作、设置 → 做进空间，不用覆盖层 |
| **"返回"变为"转回焦点"** | 没有页面栈，只有视角记忆 |

## 五、对分期的修正

| 阶段 | 原计划 | 修正后 | 说明 |
|---|---|---|---|
| **P0** | 菜单弧（2×7 网格） | **环绕菜单**：14 项沿"左后弧"排列，转动可见；☰ = 视角快捷键 | 不再是"打开的面板" |
| **P1** | 列表型空间（我的列表/歌单/排行/历史/下载） | 同左，但**列表与详情同屏**（左右分布） | 不做两级 |
| **P2** | 详情空间 | 并入 P1（同屏展开），重点做"**进入感**"转场 | |
| **P3** | 播放页扩展 | 不做"双页切换"；做**右转=操作、下转=设置、长按=操作环** | 同屏已达标 |
| **P4** | 评论/统计/设置空间 | 评论做成**播放页的环绕面**；统计/设置是独立环绕空间 | |
| **P5** | 主页丰富化 | 主页=各空间的"入口面"，信息可以存在于球面上多个深度 | |

## 六、验收标准（用来检查是否又做回"黑板"）

- [ ] 有没有"页面栈/返回键"的概念？→ 应该没有，只有"转回正面"
- [ ] 歌词、封面、进度是否同屏可看？→ 应该同时可见
- [ ] Tab 是否还在？→ 应该变成角度
- [ ] 弹窗是否存在？→ 应该变成环绕面
- [ ] 所有信息是否都能"看向它"而不是"点开它"？
