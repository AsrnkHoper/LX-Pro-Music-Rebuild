# 🛰️ LX_Pro_Rebuild 空间化建构方案
> 依据：`docs/08_LX-Pro界面调研报告.md`
> 目标：把 LX-Pro 的**全部界面与交互**，用**空间化语言**在 `prototype/app.html` 里重建
> 原则：**只做 UI 与交互，不接真实功能**；**绝不回退扁平版本**

---

## 一、设计原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **一切皆在空间里** | 没有"页面"概念，只有"空间"；切换 = 场景转场 |
| 2 | **转动视角 = 获取信息** | 核心交互。重要信息在正面，次要信息在两侧 |
| 3 | **裸元素优先** | 内容（封面/歌词/列表）不加卡片框；只有"可操作容器"才用面板 |
| 4 | **统一转场语言** | 卡片冲向镜头 → 压黑 → 新空间飞入 |
| 5 | **交互元素正对镜头** | 需要点按的（进度条/按钮/滑块）不做倾斜 |
| 6 | **氛围由相机统一提供** | 元素不各自漂浮（避免间距错乱），呼吸感靠相机 |

## 二、空间语言体系（三种形态）

### 形态 A：**球面环**（用于「总览」）
元素均匀环绕在球面上，转动视角浏览。
→ 用于：**主页 7 卡**（已实现）、~~全局菜单弧~~ ⛔ **已废弃（2026-09-22 标注）**

> ⛔ **菜单弧方案已废弃**：14 项菜单卡排成 2×7 网格浮在左后弧的方案**未落地**。
> 代码里 `MENUS` / `drawMenuGlyph` / `makeMenuCard` / `buildMenuWall` 仍在，
> 但 `buildMenuWall()` 的调用**已被注释掉**（`app.html` L1987），是死代码。
>
> **现行做法**：功能入口**直接散布在主页球面上**——7 张功能卡各占一个方位（az 0°~309°），
> 转动视角即可浏览，不需要"打开菜单"这一步。
>
> **为什么放弃**：菜单弧本质是"把抽屉导航换个形状"，仍是**两层结构**（先看菜单、再进功能）；
> 而卡片直接散布是**一层结构**，转视角就是浏览本身，更符合 `docs/10` 的
> 「凡是"切换"都改成"转动"」和「环绕比弹层高级」。
> ☰ 按钮与配套的 9 个新空间一并取消。

### 形态 B：**竖列/列表空间**（用于「内容页」）
面板在正前方按列或按列表堆叠，纵向转动浏览。
→ 用于：搜索、歌单、排行、历史、下载、评论、设置、统计

### 形态 C：**多焦点空间**（用于「播放页」）
关键内容分置在正面/左侧/右侧，**转动视角切换焦点**。
→ 用于：播放详情（封面+歌词 / 歌曲信息+队列 / 播放设置+操作）

## 五、交互设计

| 操作 | 效果 |
|---|---|
| **左右/上下拖动** | 转动视角（浏览空间） |
| **点卡片/面板** | 进入子空间（卡片冲向镜头 → 压黑 → 新空间飞入） |
| **点 ☰** | ~~打开**菜单弧**~~ ⛔ ☰ 按钮已取消（菜单弧废弃）|

| 手势 | 效果 |
|---|---|
| **左右滑** | 封面 ⇄ 歌词 双焦点切换（相机平滑移到两个焦点） |

## 六、技术实现要点

### 6.1 复用现有机制
| 机制 | 说明 |
|---|---|
| `sf/sv/fw/fh` | 屏幕比例定位，适配所有屏幕 |
| `tilt` | 固定倾斜（有透视）vs 正对镜头（可交互） |
| `bare` | 裸元素（无底板） |
| `pscale` | 排版缩放（内容放大、面板不变） |
| `float:0` | 关闭独立漂浮（保持间距稳定） |
| `cam`（每页） | 每页可自定义相机范围与灵敏度 |
| 区域命中 | `hit.uv → regions → 动作` |
| 长图 + offset | 歌词滚动（可复用于任何长列表） |

### 6.2 页面配置扩展
```js
PAGES.xxx = {
  en:'SEARCH', cn:'搜索',
  cam: { yawMax, pitchMax, sensX, sensY },   // 相机
  radius: 7,                                  // 球半径
  layout: 'free' | 'column' | 'list',         // 布局模式
  widgets: [
    { type:'search', sf:0.5, sv:0.2, fw:0.9, fh:0.08, bare:true },
    { type:'songrow', sf:0.5, sv:0.5, fw:0.9, fh:0.5, items:[...] },
    ...
  ]
}
```

### 6.3 新增布局模式
- `column`：竖列堆叠（现有）
- `free`：屏幕比例自由摆放（现有）
- **`list`**：单一大列表面板占满可视区，内部滚动
