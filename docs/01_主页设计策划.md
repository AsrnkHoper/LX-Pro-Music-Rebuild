# 🎵 音乐APP 主页设计策划
> 风格关键词：灰黑色 · 忧郁 · 高级感 · inmyfeelings · ins 冷淡风

---

## 一、设计基调（Mood & Tone）

| 维度 | 定调 |
|---|---|
| 情绪 | 忧郁、孤独、深夜感、情绪化（in my feelings） |
| 质感 | 高级、克制、留白、冷淡 |
| 参考 | Instagram 冷淡风 / 网易云「黑胶」/ Apple Music 深色 / Spotify Dark |
| 关键词 | 玻璃拟态(Glassmorphism)、微光、颗粒噪点、大圆角、低饱和 |

### 一句话概括
> 像深夜关灯后独自听歌的那种感觉——黑得干净、光得克制、情绪藏在细节里。

## 二、配色系统（Color System）

```
【背景层 Background】
  --bg-base       #0A0A0B   主背景（近黑，微微偏冷）
  --bg-elevated   #141416   卡片/浮层背景
  --bg-glass      rgba(255,255,255,0.04)  玻璃卡片

【文字层 Text】
  --text-primary  #EDEDED   主文字（不是纯白，降低刺眼）
  --text-secondary #8A8A8E  次要文字（灰）
  --text-tertiary #4A4A4E   辅助/占位（深灰）

【强调色 Accent】（忧郁风的关键：只用一点点）
  --accent        #6E7A8A   冷灰蓝（主强调，忧郁感核心）
  --accent-glow   rgba(110,122,138,0.35)  微光/发光

【情绪点缀 Emotion Accent】（可选，极少用）
  --mood-purple   #5B5468   雾紫（忧郁+高级）
  --mood-blue     #3D4A5C   深海蓝

【分隔线 Divider】
  --divider       rgba(255,255,255,0.06)
```

> 原则：**90% 灰黑 + 8% 冷灰蓝 + 2% 微光点缀**。颜色越少越高级。

## 三、字体系统（Typography）

| 用途 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 页面大标题 | 28sp | Bold / 700 | text-primary |
| 区块标题 | 18sp | SemiBold / 600 | text-primary |
| 歌曲名 | 16sp | Medium / 500 | text-primary |
| 歌手名 | 13sp | Regular / 400 | text-secondary |
| 标签/时间 | 11sp | Regular / 400 | text-tertiary |

- 字体推荐：`PingFang SC` / `HarmonyOS Sans` / `Inter`（英文数字）
- 标题可加**字间距 +0.5sp** 提升高级感
- 忧郁感来源：**大留白 + 小字重 + 灰阶层次**

## 四、主页结构（Layout）

```
┌──────────────────────────────────┐
│  ① 顶部问候区（时间 + 情绪文案）    │  Good evening.
│     "今晚也想听点安静的吗？"        │  灰阶大标题
├──────────────────────────────────┤
│  ② 搜索栏（玻璃拟态 + 圆角胶囊）    │  🔍 搜索歌曲 / 歌手
├──────────────────────────────────┤
│  ③ 情绪推荐卡（大图横滑 Banner）    │  深夜 / 孤独 / 雨天 / 失眠
│     ┌────────┐┌────────┐┌────────┐│  大圆角 24dp
│     │ 深夜   ││ 雨天   ││ 独处   ││  底部渐变遮罩
│     └────────┘└────────┘└────────┘│
├──────────────────────────────────┤
│  ④ 最近播放（横滑专辑卡）           │  圆角专辑封面 + 歌曲名
├──────────────────────────────────┤
│  ⑤ 为你推荐（竖排歌曲列表）         │  封面 + 歌名 + 歌手 + ⋮
│     ▢ 歌曲名            03:42     │  极简分隔线
│     ▢ 歌曲名            04:11     │
├──────────────────────────────────┤
│  ⑥ 底部迷你播放条（悬浮玻璃条）      │  ▢封面 歌名 ▶ ⏭
├──────────────────────────────────┤
│  ⑦ 底部导航栏（4 Tab）             │  首页 发现 歌单 我的
└──────────────────────────────────┘
```

### 各区块设计要点

**① 顶部问候区**
- 根据时间变化文案：`Good morning / Good afternoon / Good evening`
- 下方一行情绪文案：`今晚也想听点安静的吗？`（灰色小字）

**② 搜索栏**
- 胶囊形，背景 `--bg-glass`，1px 微边框 `rgba(255,255,255,0.08)`
- 放大镜图标用 `--text-secondary`，占位文字 `--text-tertiary`

**③ 情绪推荐卡（视觉焦点）**
- 尺寸：约 160×200dp，圆角 24dp
- 背景图 + 底部黑色渐变遮罩（让文字可读）
- 卡片文字：情绪名（如"深夜"）+ 副标题（如"12 首歌"）
- 忧郁感：图片统一降饱和 + 压暗处理

**④ 最近播放**
- 横滑，专辑封面 120×120dp，圆角 16dp
- 下方歌名（primary）+ 歌手（secondary）

**⑤ 为你推荐列表**
- 每行：48dp 封面（圆角 8dp）+ 歌名/歌手 + 时长 + 更多按钮
- 分隔线用 `--divider`，几乎看不见
- 点击行有水波纹（低调，`rgba(255,255,255,0.05)`）

**⑥ 迷你播放条**
- 悬浮在底部导航上方，玻璃拟态，圆角 20dp
- 左侧旋转的专辑封面（圆形），中间歌名滚动，右侧播放/下一首

**⑦ 底部导航栏**
- 背景 `--bg-elevated` 或半透明玻璃
- 选中态：`--accent` 冷灰蓝；未选中：`--text-tertiary`
- 4 个 Tab：首页 / 发现 / 歌单 / 我的

## 五、高级感细节（关键！）

1. **颗粒噪点纹理（Noise Grain）**
   - 全屏叠加 3%~5% 透明度的噪点，去掉"塑料感"，增加胶片质感

2. **微光晕（Glow）**
   - 情绪卡片/播放条边缘加 `--accent-glow` 微光，像屏幕在呼吸

3. **玻璃拟态（Glassmorphism）**
   - 播放条、搜索栏用 `BackdropFilter(blur: 20)` + 半透明背景

4. **圆角统一**
   - 卡片 24dp / 封面 16dp / 小封面 8dp / 胶囊全圆

5. **动效（克制）**
   - 页面进入：淡入 + 上移 8dp，300ms `easeOut`
   - 播放封面：缓慢旋转（20s/圈）
   - 切歌：封面交叉淡入淡出

6. **降饱和图片**
   - 所有专辑/情绪图统一 `saturation 0.8 + brightness 0.85`，统一忧郁色调

## 六、可落地技术方案（Flutter 示例）

```dart
// 主题色定义
class AppColors {
  static const bgBase      = Color(0xFF0A0A0B);
  static const bgElevated  = Color(0xFF141416);
  static const textPrimary = Color(0xFFEDEDED);
  static const textSecond  = Color(0xFF8A8A8E);
  static const textTertiary= Color(0xFF4A4A4E);
  static const accent      = Color(0xFF6E7A8A);
  static const divider     = Color(0x0FFFFFFF);
}
```

- 状态管理：`Provider` / `GetX`
- 玻璃拟态：`BackdropFilter` + `ImageFilter.blur`
- 噪点：`CustomPainter` 绘制或噪点 PNG 叠加
- 横滑：`PageView` / `ListView(scrollDirection: horizontal)`
