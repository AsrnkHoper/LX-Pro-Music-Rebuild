# 🎧 沉浸式歌曲页 设计规范

> ⛔ **本方案已废弃（2026-09-22 标注）**
>
> 本文描述的是**早期 DOM 沉浸式播放器**方案：用 HTML/CSS 做 `.np` 全屏面板，
> 封面是 WebGL 渲染的 3D 黑胶（`coverGroup`），歌词是 DOM 滚动列表（`.np-ly`）。
>
> **现行方案**：`docs/07_空间播放器规范.md` 的**空间播放器**——
> 歌词/封面/控制全部是**空间里的裸元素**（`lyric3d` / `cover` / `transport` 控件），
> 与播放页其他控件同处一个球面空间，可转动视角切换焦点。
>
> **废弃原因**：
> 1. `.np` 面板会盖住整个 3D 空间，退回成"一个页面"——违反 `docs/10` 第一条原则「一切皆在空间里」
> 2. 与空间语言冲突：播放页要求「左歌词 · 右封面 · 斜置透视」同屏，DOM 面板做不到
> 3. `body.playing` 类**从未被添加**（`openPlayer()` 定义后无人调用），
>    所以 `.np` 面板、`npPrev`/`npNext` 按钮、3D 黑胶 `coverGroup` 实际全部**不可见不可达**
>
> **保留原因**：作为技术储备留档——3D 黑胶的纹理生成（`makeVinylTexture` / `makeLabelTexture`）、
> 歌词自动跟随与手动滚动暂停（`progScrollUntil`）、闲置隐去控件（`np-idle`）等思路仍有参考价值。
>
> **⚠️ 阅读提醒**：本文的 CSS 类名（`.np-*`）、函数名（`layoutVinyl` / `openPlayer`）、
> 参数表**均对应当前代码中的死代码**，不要据此判断现有行为。现行播放页请读 `docs/07`。

## 一、调研结论（设计依据）

| 来源 | 关键手法 |
|---|---|
| Refined Now Playing（网易云插件） | **去掉冗余元素**、专辑封面**自动生成模糊背景**、半透明控制栏、"电影院般的沉浸感" |
| Folia（开源播放器） | **全屏沉浸式歌词** |
| NebulaPlayer | **粒子随节拍呼吸**，电影级沉浸 |
| 酷狗 | 歌词**视觉化**、黑胶**拟物感** + 流体动效、"仪式感" |
| YouTube Music | 全屏 Now Playing |

**核心原则**：`去冗余` + `封面驱动氛围` + `歌词为主角` + `粒子呼吸` + `半透明控件`

## 三、关键技术实现

### 1. 封面 = 3D 黑胶唱片（不是卡片）

```
CircleGeometry(1, 96)          ← 唱片本体
  + 黑胶贴图（78 圈细纹 + 斜向高光）
CircleGeometry(0.48, 64)       ← 中心圆标（封面色）
  + 渐变 + 弧线装饰 + 中心孔
Sprite(光环)                    ← 背后柔光
```

- 整组**按屏幕尺寸自动定位**（`layoutVinyl()`）
  - 距离 8 单位，直径 = 屏宽 × 62%
  - 位置：屏幕纵向约 22%
- 持续绕 Z 轴旋转（0.42 rad/s）
- 轻微上下浮动 + 微幅摆动

### 2. 歌词：自由滚动 + 自动跟随

| 机制 | 实现 |
|---|---|
| 上下渐隐 | CSS `mask-image: linear-gradient` |
| 当前句高亮 | `.on` 类 → 更大字号 + 更亮 + 发光 |
| 相邻句半亮 | `.near` 类 |
| 自动跟随 | 当前句变化时 `scrollTo` 到 42% 位置 |
| **用户可自由滚动** | 检测到手动滚动 → **暂停自动跟随 4 秒** |
| 区分程序/手动滚动 | 时间戳标记 `progScrollUntil` |

### 3. 进度条：可拖动

- Pointer Events（`pointerdown/move/up`）+ `setPointerCapture`
- 拖动时**实时更新**进度、时间、歌词高亮
- 拖动中**暂停播放推进**（`NP.dragging`）
- 拖动时圆点放大（`.drag`）

### 4. 氛围联动

| 元素 | 联动 |
|---|---|
| **封面色晕** | 从歌曲 `accent` 色生成背景光晕（`--wash`），切歌时 1.2s 过渡 |
| **粒子呼吸** | 尘埃透明度随 `sin(t*2.1)` 在 0.24~0.44 间呼吸 |
| **胶片颗粒** | `.np::after` 覆盖歌曲页 |
| **暗角** | 径向渐变收拢视线 |

### 5. 沉浸感

- **闲置 4.5 秒** → 顶栏 + 控制栏淡到 10%，进度条淡到 22%
- 一碰屏幕立刻恢复
- 相机完全固定（只有 0.05 幅度的呼吸），避免画面晃动
- 无任何卡片边框，全部元素直接浮在深空里

## 四、数据与状态

```jsconst TRACKS = [
 { title, artist, dur, accent, lyrics:[{t,s}, ...] },
 ...

const NP = { idx, cur, playing, dragging, autoFollow, followTimer };
```

## 五、可调参数

| 想改 | 改哪 |
|---|---|
| 黑胶大小 | `layoutVinyl()` 里 `halfW * 0.62` |
| 黑胶高低 | `layoutVinyl()` 里 `halfH * 0.56` |
| 转速 | `spinner.rotation.z -= dt * 0.42` |
| 歌词字号 | CSS `.np-ly` / `.np-ly.on` |
| 自动跟随位置 | `updateLyrics()` 里 `clientHeight*0.42` |
| 手动滚动暂停时长 | `setTimeout(..., 4000)` |
| 闲置隐去时间 | `npIdleT > 4.5` |
| 粒子呼吸幅度 | `0.34 + Math.sin(t*2.1)*0.10` |
| 曲目/歌词 | `TRACKS` 数组 |
