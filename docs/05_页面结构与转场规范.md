# 🧭 页面结构与转场规范
> 对应文件：`prototype/app.html`

---

## 一、页面层级

```
主页 (mode = 'main')
 └── 球面上环绕 6 张功能卡
     ├── 搜索        → 子页面：搜索栏 / 搜索记录 / 热门搜索 / 搜索结果
     ├── 我的歌单     → 子页面：我创建的 / 我收藏的 / 最近添加 / 歌单导入
     ├── 听歌统计     → 子页面：听歌时长 / 歌手排行 / 歌曲排行 / 听歌习惯
     ├── 当前播放     → 子页面：播放队列 / 歌词 / 歌曲信息 / 音效
     ├── 下载管理     → 子页面：已下载 / 下载中 / 下载设置 / 存储空间
     └── 设置        → 子页面：外观主题 / 播放设置 / 音质下载 / 关于

子页面 (mode = 'sub')
 └── 浅球面上 2 列 × N 行卡片阵
```

## 二、转场：主页 → 子页面

**核心：动的是卡片，不是相机。**

| 时间 | 发生什么 |
|---|---|
| 0 ms | 点击卡片 |
| 0 ms | UI 全部隐去（`body.busy`） |
| 0 → 400 ms | **被点的卡片加速冲向镜头**（`e = k²` 加速曲线），同时放大 9 倍，其余卡片淡出 |
| 300 ms | 开始压黑（`.fx-wipe`，150 ms 渐入） |
| 470 ms | **切换场景**：主页组隐藏 → 子页面组显示，卡片复位 |
| 470 ms | 压黑解除（340 ms 渐出），**子页面卡片从远处飞入**（错落 55 ms 逐个） |
| ~1.4 s | 全部就位，转场结束 |

**关键参数**
| 参数 | 值 | 位置 |
|---|---|---|
| 卡片飞行时长 | 0.40 s | `flyCard.dur` |
| 放大倍数 | 9× | `1 + e*8` |
| 压黑延迟 | 300 ms | `setTimeout` |
| 切换时刻 | 470 ms | `setTimeout` |
| 入场时长 | 0.5 s + 错落 | `enterT/0.5` |

## 三、相机行为（两种模式）

| 参数 | 主页 main | 子页面 sub | 说明 |
|---|---|---|---|
| **左右转动上限** | ±3.14 rad（180°） | **±0.55 rad（31.5°）** | 子页面转动受限 |
| **上下转动上限** | ±1.30 rad（74°） | **±0.34 rad（19.5°）** | 同上 |
| **横向灵敏度** | 0.012 | **0.006**（减半） | 子页面更迟钝 |
| **纵向灵敏度** | 0.008 | **0.004**（减半） | 同上 |

> 子页面因为转动受限，所以卡片都排在**前方浅球面**上，全部可见。

## 四、子页面布局

```
      ┌────────┐  ┌────────┐
      │ 卡片 1  │  │ 卡片 2  │    ← 仰角 +10°
      └────────┘  └────────┘
      ┌────────┐  ┌────────┐
      │ 卡片 3  │  │ 卡片 4  │    ← 仰角 -10°
      └────────┘  └────────┘
          ↑            ↑
      方位 -10°     方位 +10°
```

- 2 列 × N 行，铺在半径 8.2 的浅球面上
- 行间距 20° 仰角，列间距 10° 方位
- 卡片尺寸 2.35 × 1.52（比主页卡小，体现"进入"层级）

---

## 五、返回：子页面 → 主页

| 时间 | 发生什么 |
|---|---|
| 0 ms | 点「← 返回主页」 |
| 0 ms | 立即压黑 |
| 260 ms | 切换：子页面组隐藏 → 主页组显示 |
| 260 ms | 压黑解除，**主页 6 张卡片从远处飞回** |

## 六、可调参数

| 想改 | 改哪 |
|---|---|
| 子页面卡片内容 | `SECTIONS` 对象 |
| 子页面转动范围 | `CAM.sub.yawMax / pitchMax` |
| 子页面灵敏度 | `CAM.sub.sensX / sensY` |
| 子页面卡片尺寸 | `SUB_W / SUB_H` |
| 子页面球半径 | `buildSub()` 里的 `R2` |
| 子页面行列间距 | `layoutSub()` 里的 `azStep / elStep` |
| 卡片飞行速度 | `flyCard.dur` |
| 飞行放大倍数 | `1 + e*8` 里的 8 |
| 入场错落间隔 | `playEnter()` 里的 `i * 0.055` |
| 压黑时长 | CSS `.fx-wipe` 的 `transition` |
