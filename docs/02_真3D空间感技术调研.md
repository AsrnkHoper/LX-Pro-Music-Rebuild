# 🔭 真·空间感 / 立体感 技术调研
> 目标：音乐APP主页不是"卡片浮动"，而是**真的置身于三维空间**

---

## 一、核心结论：分清两种"3D"

调研中看到一个关键判断标准（来自 CSDN 星空隧道文章）：

> **"几何观光型"用 CSS；"场景模拟型"用 WebGL。**
> 装饰性动效 → CSS 够用；真正的空间沉浸 → 必须 WebGL。

| 类型 | 技术 | 效果 | 适合 |
|---|---|---|---|
| ❌ 假 3D | CSS `perspective` + `translateZ` | 元素前后浮动，本质还是平面图层 | 卡片翻转、装饰 |
| ✅ 真 3D | **WebGL / Three.js** | 真实三维坐标、透视、光照、相机 | 空间场景、沉浸体验 |

**你要的"真空间感、立体感"= 必须上 Three.js（WebGL）。**

---

## 二、Three.js 实现真空间的核心概念

Three.js 的世界里，一切都在**真实的三维坐标系**中：

```
        Y (上)
        |
        |
        |________ X (右)
       /
      /
     Z (朝向观察者)

相机(Camera) = 你的眼睛，在 3D 空间里有个真实位置
场景(Scene)  = 整个空间
物体(Mesh)   = 空间里真实存在的对象，有 x/y/z 坐标
光照(Light)  = 让物体有明暗立体感
```

**关键差异：**
- CSS 的 Z 轴是"层级"，越大越靠前，但**不会因为相机移动产生透视变化**
- Three.js 的 Z 轴是**真实深度**，相机在空间里移动，物体会产生**近大远小的透视**，这就是真空间感

## 三、音乐APP 的"真空间"可以做哪些设计

### 方案 A：星空隧道 / 深空漂移（推荐）
- 相机在 3D 空间里**缓慢向前飞行**
- 歌单封面变成**悬浮在空间中的立方体/面板**，散布在 Z 轴不同深度
- 越远的越小越暗（雾效 Fog），形成无限纵深
- 适合：忧郁、深空、孤独感 —— **和你的灰黑忧郁风完美契合**

### 方案 B：3D 唱片墙 / 环形歌单
- 专辑封面排列成一个**圆弧墙**，围绕相机
- 左右滑动 = 相机旋转，封面随之转向
- 真实透视让近处封面大、远处小

### 方案 C：音乐可视化空间（音频驱动）
- 用 `Web Audio API` 分析频谱
- 3D 粒子/波形**随音乐节奏跳动**（调研案例正是这么做的）
- 粒子在三维空间里飞舞，相机可环绕

### 方案 D：悬浮黑胶唱片
- 一张**真实 3D 的黑胶唱片**悬浮在空中
- 有厚度、有光泽、有投影
- 播放时旋转，相机可轻微环绕

## 五、Android 13+ 上的落地方式

HTML 演示用 Three.js 没问题，但**正式 Android APP** 有三种路径：

| 路径 | 说明 | 推荐度 |
|---|---|---|
| **1. Flutter + flutter_gl / three_dart** | 跨平台，但 Three.js 移植有坑 | ⭐⭐ |
| **2. Flutter + Filament (scene) / Rive** | 原生级 3D，性能好 | ⭐⭐⭐ |
| **3. Android 原生 + OpenGL ES / Filament** | 性能最强，开发成本高 | ⭐⭐⭐⭐ |
| **4. WebView + Three.js** | 直接复用 HTML 原型，最快验证 | ⭐⭐⭐（原型阶段） |

> 建议：**原型阶段用 WebView + Three.js 验证效果**，效果好再决定是否用原生渲染重写。
